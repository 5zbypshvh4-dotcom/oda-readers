# ODA Readers

Односторінковий сайт книжкового клубу ODA Readers (Бухарест і Клуж-Напока).

## Локальний перегляд
Просто відкрий `index.html` подвійним кліком у будь-якому браузері — окремий сервер не потрібен.

## Структура
- `index.html` — весь сайт (розмітка, стилі, логіка) в одному файлі
- `photos/` — фото зустрічей та банер-заглушка для подій

## Підʼєднання Google Таблиці (події, книги)
Відкрий `index.html`, знайди блок `CONFIG` на початку `<script>` і встав туди лінки:

```js
const CONFIG = {
  EVENTS_CSV_URL: '',   // Google Sheets → Share → Publish to web → CSV
  BOOKS_CSV_URL: '',
  SIGNUP_ENDPOINT_URL: '' // Google Apps Script Web App для запису реєстрацій
};
```

Формат колонок таблиць описаний коментарем прямо над `CONFIG` у файлі.

## Деплой
Репозиторій готовий для Cloudflare Pages / GitHub Pages — це звичайний статичний сайт,
build-команда не потрібна (публікувати можна прямо корінь репозиторію).
