# Спільний час — планувальник дзвінків (прототип)

Простий спосіб знайти час для дзвінка в невеликій спільноті (4–10 людей) без нескінченних голосувань.

## Як це працює

1. **Організатор** створює дзвінок: тема, тривалість, діапазон дат, дозволені години
   (наприклад, 10:00–20:00, а нічний час взагалі не показується), скільки часу на відповіді
   (таймер) і, за бажанням, список учасників.
2. Отримує посилання і **надсилає його в групу WhatsApp** однією кнопкою.
3. **Учасник** відкриває посилання, вводить ім'я і:
   - натискає «Підтягнути вільний час з Google Calendar», і вільні слоти позначаються автоматично;
   - або сам проводить пальцем по сітці, коли йому зручно.
4. Поки йде таймер, організатор бачить, хто вже відповів, і може **нагадати тим, хто ні**:
   відкривається WhatsApp з готовим текстом та іменами.
5. Система показує **топ-3 слоти** (спершу ті, де можуть усі, потім за кількістю людей,
   за рівних умов найближчий) і теплову карту «як зручно всім».
6. Організатор **обирає час**, і всі бачать фінальну картку з кнопкою «Додати в Google Calendar»,
   а організатор отримує готове повідомлення для групи.

## Безкоштовний запуск: Google Apps Script + Google Таблиця (основний спосіб)

Сайт лежить разом із сайтом ODA Readers на GitHub/Cloudflare Pages, а дані зберігаються
в окремій Google Таблиці, яку бачиш лише ти. Без оплати і без серверів.

1. Створи **нову** Google Таблицю (sheets.new), наприклад «Спільний час — дані».
2. **Розширення → Apps Script**. Видали код-заглушку і встав увесь вміст `call-planner/apps-script.gs`, потім збережи.
3. Угорі вибери функцію **`setup`** і натисни **▶ Виконати**. Дозволь доступ: якщо з'явиться
   «Google не перевірив цей додаток», натисни **Додатково → Перейти до проєкту**.
   У таблиці з'являться вкладки `Polls` і `Responses`.
4. **Розгорнути → Нове розгортання → Веб-додаток**. Виконувати як: **Я**, доступ: **Усі**.
   Натисни «Розгорнути» і скопіюй URL (закінчується на `/exec`).
5. У `call-planner/index.html` знайди рядок `const API_URL = '';` і встав URL між лапками.
6. Збережи зміни в гілці `main`. Сторінка буде доступна за адресою `<адреса-сайту>/call-planner/`.

Після зміни `apps-script.gs` онови розгортання: **Розгорнути → Керувати розгортаннями → ✏️ →
Нова версія**. URL при цьому не змінюється.

## Запуск на своєму комп'ютері (для розробки)

Потрібен лише [Node.js](https://nodejs.org) 18+, без жодних залежностей:

```bash
cd call-planner
node server.js
```

Відкрий http://localhost:3000. Дані зберігаються в `call-planner/data/polls.json`.

### Демо-режим (без сервера)

Якщо просто відкрити `index.html` (або сторінку `/call-planner/` на GitHub/Cloudflare Pages),
прототип працює в **демо-режимі**: дані зберігаються лише в цьому браузері. Цього достатньо,
щоб «помацати» інтерфейс. Кнопка «+ Тестові учасники» на панелі організатора додає вигаданих
людей, щоб побачити, як працюють результати.

## Що в прототипі поки імітується

| Функція | Зараз | У робочій версії |
|---|---|---|
| Google Calendar | випадкова «зайнятість» (демо) | Google OAuth + FreeBusy API (лише зайнято/вільно) |
| Подія після вибору | посилання «Додати в Google Calendar» | автоматична подія з Google Meet і запрошеннями всім |
| Нагадування | організатор надсилає в WhatsApp вручну (готовий текст) | можна додати автоматичні листи |
| Часовий пояс | один для всіх (Київ) | пояс кожного учасника |

## Файли

- `index.html`: увесь інтерфейс (сторінки організатора і учасника, алгоритм підбору слотів)
- `apps-script.gs`: бекенд для Google Apps Script (основний, безкоштовний)
- `server.js`: мінімальний сервер для запуску на своєму комп'ютері (Node.js, без залежностей)

Сторінка сама вибирає, звідки брати дані: якщо заповнено `API_URL`, то з Apps Script;
якщо поруч працює `server.js`, то з нього; інакше вмикається демо-режим.

## API (для розробки)

| Метод | Шлях | Опис |
|---|---|---|
| `GET` | `/api/health` | перевірка сервера |
| `POST` | `/api/polls` | створити дзвінок → `{id, adminToken}` |
| `GET` | `/api/polls/:id` | дзвінок і відповіді (без токена) |
| `POST` | `/api/polls/:id/responses` | зберегти/оновити відповідь `{name, cells[]}` |
| `POST` | `/api/polls/:id/close` | завершити збір (`adminToken`) |
| `POST` | `/api/polls/:id/finalize` | обрати час `{adminToken, final:{date,start,link}}` |
